# شركة ألفا بول - Alpha Pool (تطبيق أندرويد)

تطبيق أندرويد متكامل (عربي / RTL) لإدارة شركة صيانة وإنشاء حمامات السباحة والمقاولات، مبني بـ **Kotlin + Jetpack Compose (Material 3)** ويعمل **محليًا بالكامل بدون إنترنت** عبر قاعدة بيانات **Room/SQLite**، مع العملة بالجنيه المصري (ج.م).

## أبرز ما يقدمه التطبيق
- 9 كيانات: العمال والسائقين، الحضور والإجازات، العهدة، المصاريف الشخصية، السلف، خصومات السلف الشهرية، توريدات وحسابات العملاء، إعدادات الراتب الشهرية الاستثنائية، والملاحظات.
- تعبئة تلقائية ببيانات عمال تجريبية عند أول تشغيل (إذا كانت القاعدة فارغة).
- محرك حساب رواتب شهري موحد (أجر يوم، بدلات سفر/سهر، حوافز، خصومات عهدة/سلف/غياب/إجازة، صافي تلقائي أو معدل يدويًا، ورصيد سلف متبقٍ).
- 5 أقسام رئيسية قابلة لإعادة الترتيب: الرئيسية، العمال، الرواتب، العملاء، الملاحظات + مبدّل علوي سريع.
- شاشات تفصيلية للعمال والرواتب والعملاء والملاحظات مع إضافة/تعديل/حذف وسجلات تاريخية.
- تقارير وتصدير: PDF لكشوف الرواتب (فردي/شهري) وفواتير العملاء، وتصدير CSV (UTF-8 BOM) شامل، ونسخ احتياطي/استيراد JSON (ملف أو لصق نص).
- تخصيص ترتيب عناصر التنقل وكروت الإضافة السريعة مع حفظ محلي.

## هل يمكن استخراج APK بدون Android Studio؟
نعم، لديك بدائل (ولا يوجد ملف APK جاهز داخل هذا المجلد لأن بناءه يحتاج أدوات أندرويد غير متوفرة هنا):

1. **أسهل خيار بدون تثبيت أدوات برمجية (موصى به): GitHub Actions**
   - المشروع يحتوي على Workflow جاهز: `.github/workflows/android.yml`
   - ارفع محتويات مجلد `AlphaPool` إلى مستودع GitHub ثم شغّل الـ Action (يدويًا من تبويب Actions > Run workflow أو بدفع commit).
   - بعد انتهاء البناء حمّل ملف APK من **Artifacts** باسم `AlphaPool-debug-apk` وثبّته على الهاتف (قد تحتاج تفعيل التثبيت من مصادر غير معروفة).
   - راجع الخطوات التفصيلية في `BUILD_WITHOUT_ANDROID_STUDIO.md`.

2. **أدوات سطر الأوامر فقط (بدون واجهة Android Studio)**
   - ثبّت: JDK 17 + Android SDK Command-line tools + حزم (`platforms;android-35`, `build-tools;35.0.0`, `platform-tools`).
   - من داخل مجلد المشروع نفّذ أمر البناء (مثلاً عبر Gradle المثبّت: `gradle :app:assembleDebug`).
   - ستجد الناتج في: `app/build/outputs/apk/debug/`.
   - هذا الخيار أخف من تثبيت Android Studio لكنه ما زال يتطلب إعداد SDK محليًا.

3. **خدمات بناء سحابية أخرى**
   - مثل Codemagic أو Bitrise أو Appcircle، لكنها تحتاج إنشاء حساب وضبط إعدادات؛ خيار GitHub Actions مجهز مسبقًا في المشروع.

4. **أن يبنيه لك شخص آخر**
   - يمكنك ضغط مجلد المشروع `AlphaPool` وإرساله لشخص لديه بيئة بناء أندرويد (Android Studio أو أدوات SDK) ليُخرج لك ملف APK.

## البناء عبر Android Studio (إن رغبت لاحقًا)
1. افتح مجلد `AlphaPool` في Android Studio (مع JDK 17 و Android SDK 35).
2. انتظر Gradle Sync.
3. شغّل على محاكي/جهاز (Min SDK 26) أو ابنِ APK من: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.

## بنية مختصرة
- `app/src/main/java/com/alphapool/app/data/...` — Room (كيانات، DAO، قاعدة بيانات، مستودع وتفضيلات)
- `app/src/main/java/com/alphapool/app/domain` — محرك حساب الرواتب
- `app/src/main/java/com/alphapool/app/ui` — الشاشات، التنقل، الثيم، و ViewModel
- `app/src/main/java/com/alphapool/app/util` — التاريخ/العملة، PDF/CSV، النسخ الاحتياطي والمشاركة
